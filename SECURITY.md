# Security policy

## Supported versions

Only the latest version on `main`, deployed at https://patrickking67.github.io/commute-analyzer/,
gets fixes.

## Reporting a vulnerability

Report privately through
https://github.com/patrickking67/commute-analyzer/security/advisories/new. Please do not open a
public issue.

Include what you found, how to reproduce it and what an attacker could do with it.

## Scope

In scope: the code in this repository and the site it builds, including how it handles
address search responses and the generated PDF.

Out of scope: OpenStreetMap Nominatim, Google Fonts and GitHub Pages themselves, and
advisories in dependencies with no path to exploit in this app (report those upstream).

## What to expect

This is a personal project maintained in spare time. Expect an acknowledgement within 7 days
and an update on a fix or decision within 30 days.
